# 🚇 Métro Écologique – Recherche de trajets optimisés & estimation de CO₂

Ce projet fullstack (Vue.js + Flask) permet de rechercher le **trajet de métro le plus court** en Île-de-France en utilisant les données **GTFS** d’Île-de-France Mobilités (IDFM), tout en estimant l’impact **CO₂** du trajet.
